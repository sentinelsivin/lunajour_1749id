# Lunajour

Веб-приложение: фото видно сквозь звёзды, точки, слова и другие фигуры на листе бумаги.
Сервер и база данных не нужны, вся обработка идёт на устройстве.

## Запуск на компьютере

```bash
node serve.mjs
```

Затем открой http://localhost:5173

## Как добавлять своё

| Что добавить | Где |
|---|---|
| Новая фигура | Одна строка в списке `MOTIFS` в `js/motifs.js` |
| Шрифт | Файл в `fonts`, `@font-face` в `style.css`, строка в `WORD_FONTS` в `js/motifs.js`; он появится и в словах, и в подписи |
| Вид бумаги | Строка в `PAPERS` и ветка в `paintPaper` в `js/render.js` |
| Фигура для ручной расстановки | `SYMBOLS` в `js/motifs.js`, контур в сетке 24 × 24 |
| Пиксельный рисунок | Новый рисунок в `SPRITES` в `js/motifs.js` |
| Шаблон коллажа | Строка в `COLLAGES` в `js/collages.js`: ячейки, рамки, подложка. Фразы и рамки вокруг людей раскладываются функцией `layout` |
| Стикер-эмодзи | Строка `EMOJIS` в `js/app.js`. Свои картинки-стикеры загружаются прямо в приложении, раздел «Текст» → «Стикеры и надписи» |
| Шаблон цвета по таблице | Файл `luts/<id>.txt` (таблица 17 × 17 × 17 в base64) и строка в `LOOKS` в `js/render.js` с `lut: '<id>'`. Таблица подгружается, только когда шаблон выбран |
| Встроенная мелодия для видео | Строка в `TRACKS` и ветка с тем же `id` в `synth()` в `js/music.js`: мелодия собирается кодом из простых звуков, громкость выравнивается сама |
| Эффект для стикеров | Строка в `STICKER_FX` в `js/render.js`: простой красит пиксели сам, остальные берут эффект из `js/effects.js` с нужным видом |
| Шаблон фона | Картинка в `templates/backgrounds` и строка в `js/templates.js` |
| Перевод на английский | Словарь `EN` в `js/i18n.js`, ключ это русская строка |
| Цвета бумаги и штампы настроения | `PAPER_COLORS` и `MOODS` в `js/app.js` |
| Инструмент влога | Кнопка в `syncTools` и ветка в `syncSheet` в `js/vlog-ui.js`; если меняет кадр, поле клипа в `newClip` (`js/timeline.js`) и его отрисовка в `drawFrame` (`js/vlog-engine.js`) |
| Переход во влоге | Строка в `TRANSITIONS` и ветка в `compose` в `js/vlog-engine.js`: на входе два готовых кадра и доля перехода от 0 до 1 |
| Анимация надписи во влоге | Строка в `ANIMS` и ветка в `overlayLayer` в `js/vlog-engine.js`: меняет прозрачность, размер или место слоя |
| Шрифт подписи | `FONTS` в `js/render.js` и ссылка на шрифт в `index.html` |

Картинку можно загрузить и прямо в приложении: как фон («Макет» → «Бумага») или как вырез
(«Эффекты» → «Фигуры», категория «Моё»).

## Как выложить и открыть на телефоне

Камера на телефоне работает только по HTTPS, поэтому приложение живёт на бесплатном хостинге.

```bash
node build.mjs
```

Команда соберёт папку `dist`. Загрузи её на https://app.netlify.com/drop, открой адрес на телефоне
и добавь приложение на главный экран. После правок собери `dist` заново и загрузи на тот же сайт.

## Что где лежит

- `js/motifs.js`: каталог фигур
- `js/render.js`: сборка карточки
- `js/collages.js`: шаблоны коллажей
- `js/camera.js`: камера и запись клипа
- `js/export.js`: сохранение картинок и видео
- `js/store.js`: черновик на устройстве
- `js/app.js`: интерфейс
- `js/timeline.js`: влог, модель проекта: клипы, обрезка, разрезание, порядок, отмена
- `js/vlog-engine.js`: влог, кадр в момент времени, воспроизведение со звуком и запись ролика
- `js/vlog-ui.js`: влог, экран монтажа: лента, инструменты, настройки
- `js/decor.js`: символы, орнамент и зерно
- `style.css`: цвета и шрифты интерфейса, все значения в начале файла
